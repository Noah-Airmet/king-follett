# history/

First-pass artifacts from January 2026, kept for the record and superseded by
`data/` and `src/kf/`. `alignment_map.legacy.json` aligned the witnesses by
text snippets rather than offsets, and roughly sixteen of its pointers did not
resolve or overlapped the previous section; `collation_map.legacy.json` carried
verification notes taken from JSP manuscript scans that this repository no
longer holds. `PROJECT-OVERVIEW.md` describes a layout the project never had.

Nothing here is authoritative. Do not build on these files; read `data/` and
the root `README.md` instead.
